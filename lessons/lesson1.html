Help with microphone settings / Ayuda con la configuración

Windows: Settings → Privacy & security → Microphone; allow microphone access and desktop apps. Also check Settings → System → Sound → Input.

Windows: Configuración → Privacidad y seguridad → Micrófono. Permite el acceso. Comprueba Sistema → Sonido → Entrada.

Mac: System Settings → Privacy & Security → Microphone. / Configuración del Sistema → Privacidad y seguridad → Micrófono.

Chrome/Edge: Select the site controls icon next to the address → Site settings → Microphone → Allow, then refresh. / Selecciona el icono junto a la dirección → Configuración del sitio → Micrófono → Permitir y actualiza la página.

Testing may request microphone permission. Audio is checked on your device and is not saved by Kandd Learning. The optional speech test may send audio to your browser's speech recognition provider. / La prueba puede pedir permiso. Kandd Learning no guarda grabaciones. El reconocimiento de voz puede enviar audio al proveedor del navegador.
